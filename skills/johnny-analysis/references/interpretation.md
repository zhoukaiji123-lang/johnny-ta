# 解读参考

计算规则已在代码中冻结（见 `jta/` 各模块的文档字符串）。本文件只保留
**如何解读计算结果**的部分，不重复任何公式。

## 状态分级

| phase | 含义 | 可做什么 |
|---|---|---|
| downtrend | 日线低高点下移且 EMA 空头 | 不接下跌刀；反弹只做短线 |
| stabilizing | 结构仍弱但 EMA 已不空头 | 下跌动能减弱，不等于反转 |
| range_or_mixed | 结构混合 | 优先等待，警惕中间区来回受损 |
| reversal_candidate | 高低点抬升但 EMA 未完全多头 | 需要回踩确认与更高低点 |
| trend_improving | 高低点抬升且 EMA 多头 | 回踩支撑可参与，仍需失效位 |

`phase` 只描述结构，不预测方向。同一个 phase 在不同位置（贴支撑 vs 贴压力）
对应完全不同的动作，必须结合 `position_zone` 一起读。

## 结构角色的用途区分

| role | 用途 | 注意 |
|---|---|---|
| immediate_defense | 持仓防守枢轴 | 常常**不适合新开仓**，但失守会改变持仓动作 |
| executable_pullback | 可执行回踩支撑 | 主要的新仓候选 |
| core_defense | 更深核心防守 | 深度低吸，需要更强确认 |
| immediate_resistance | 即时阻力/减仓位 | 分批止盈参考 |
| breakout_confirmation | 突破确认位 | 站上并回踩成功才加仓 |
| higher_target | 更高止盈目标 | 未突破前不假设一定到达 |

一个点"重要"和"适合新开仓"是两件事。收益风险比不足可以否决新开仓，
但不能因此把它从关键位表里删掉。

## 证据来源怎么读

`evidence_families` 里的取值含义：

- `fib`：主波段回撤/反弹、局部导航、嵌套锚点
- `extension`：早期推动段扩展
- `pivot`：有多次真实触碰的水平枢轴（`detail.touches` 是触碰次数，
  `detail.flipped` 为真表示该位发生过支撑/压力互换）
- `prev_session` / `gap` / `round_number`：前一交易日高低收、未回补缺口边缘、整数关口
- `trendline` / `channel`：动态趋势结构
- `ema` / `vegas`：EMA8/13/21 与 EMA144/169 隧道

枢轴类证据优先于 Fib：Johnny 方法先看裸 K 与成交量，再叠指标。
两个来源落在同一价位算共振，但共振不改变"必须等确认信号"这一条。

## 嵌套锚点 Fib 为什么常常是空的

代码要求台阶底必须是算法识别的摆动低点，且通过突破基座校验
（后续反弹幅度达标 + 起始放量），数量上限 4 个。达不到就返回空。

这是刻意的。固定一个高点、对任意历史低点取 0.618，可以生成任意价位——
原 skill 的证据文件自己承认某组常被引用的支撑是从答案逆向重建出来的锚点。
输出里没有嵌套阶梯，说明当前数据支撑不了这个结构，不是计算遗漏。

## 报告里不会有的东西

- 精确挂单价：所有关键位都是路径节点，触及不等于成交
- 概率与胜率：没有前向样本前不做任何概率陈述
- 市值里程碑：按项目决定未移植
- TD Countdown 13：未实现，只有 Setup 9
