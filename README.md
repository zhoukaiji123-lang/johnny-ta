# johnny-ta

把 [johnny-finance-skill](https://github.com/m4yOvO/johnny-finance-skill) 的技术分析方法
从 prompt 层下沉为确定性计算层。

## 为什么要改造

原 skill 是纯 prompt，没有任何代码。三个后果：

1. **数据靠模型记忆。** skill 不含数据源，模型在没有实时 OHLCV 时可能编造 K 线。
   Fib 锚点错一个，整张关键位表全错，而且不会报错。
2. **锚点可以手选。** "嵌套锚点 Fib"允许固定一个高点、对任意历史台阶底取 0.618。
   台阶由人挑，就能凑出任意价位——原项目的 `evidence-map.md` 自己承认某组常被引用的
   MU 支撑是从答案逆向重建出来的锚点。
3. **共振评分是等权求和。** 八项证据彼此高度相关（Fib 与整数关口、EMA 簇与趋势线），
   相加得到的分数没有统计含义，5–8 分算"强"的阈值也是拍的。

本项目把计算全部交给代码，锚点由算法冻结，评分改为只报证据类型不做加权，
并让每一步都能在指定时点回放（`--as-of`），从而可以前向验证。

## 安装

```bash
uv venv --python 3.13
uv pip install -e ".[dev]"
```

## 用法

```bash
jta analyze MU --benchmark SOXX --account 100000     # 人读
jta analyze MU --benchmark SOXX --json               # 给 skill 叙事层消费
jta analyze MU --as-of 2026-06-01                    # 前向测试：只用该时点前的数据
jta fetch MU -i 4h --tail 6                          # 检视行情
```

## 架构

```text
jta/
├── data/          provider 抽象 + yfinance 实现 + parquet 缓存 + 4H 重采样
├── indicators/    EMA、Wilder ATR、TD Setup、摆动点检测、价格行为
├── levels/        四套 Fib、水平枢轴/缺口/整数关口、趋势线与通道、候选构建
├── scoring.py     八项共振检查（只报证据，不加权）
├── analyze.py     编排：行情 → 指标 → 候选 → 证据 → 每侧 2–3 个关键位
└── report.py      文本渲染与仓位反推

skills/johnny-analysis/    改造后的 skill：只消费 JSON，不自行计算
```

## 关键设计决定

**摆动点算法冻结。** 分形检测（左右各 k 根严格极值）→ 强制 high/low 交替 →
ATR 倍数过滤幅度。每个点带 `confirmed_at`（比摆动本身晚 k 根），
前向测试只能使用已确认的点，杜绝用"当时看不见的低点"事后画 Fib。

**Fib 只接受 SwingPoint 作锚点**，不接受裸价格。嵌套锚点额外要求台阶通过
突破基座校验（反弹幅度 + 起始放量），上限 4 个，达不到就返回空列表。

**两个半径分开。** 去重半径 0.05 ATR（只合并"同一个数字"），共振半径 0.25 ATR
（统计一个点周围有哪些证据）。用同一个半径做两件事，必然要么吞掉独立点位、
要么算不出共振——这是原 skill 那段拗口规则想表达但没能说清的东西。

**不做价格贴合。** 原 skill 允许把 Fib 原值贴到附近枢轴上展示。在确定性计算里这有害：
会让两个独立候选显示成同一个数字。重合关系只进证据栏，展示价始终是自己的计算值。

**最小间距 0.5 ATR。** 候选全部保留在内部，但输出的 S1/S2/S3 必须能回答
"失守后看哪一档"，三个挤在 0.3 ATR 内的点做不到这件事。被间距规则挤掉的点
会在 `selection.crowded_out` 里列明原因。

**证据不足就少输出。** 每侧最多 3 个，达不到最低证据标准就输出实际数量并说明缺口，
不用弱点补位。

## 口径

- **复权**：后复权（历史价调整，最新价保持真实成交价），与整数关口、真实枢轴同口径。
  `--adjust raw` 可取未调整价做锚点敏感性检查。
- **4H bar**：yfinance 无原生 4H。以每交易日常规盘开盘为起点按 4 小时切分，
  常规日两根（09:30–13:30 / 13:30–16:00 ET），半日市一根，时间戳为 bar 开始时间。
  与 TradingView 美股 4H 一致。
- **时间精度**：yfinance 1.6 与 parquet 往返会返回 `datetime64[ms]`。所有整数时间算术
  前统一 `as_unit("ns")`——按错误单位解释 epoch 纳秒会让时间戳静默塌缩到 1970 年。
- **ATR**：Wilder 平滑（首值取前 14 根 TR 简单平均）。只用于执行容差、止损缓冲、
  仓位反推，不用于合并承担不同触发作用的相邻关键位。
- **EMA**：`adjust=False` 递推，与 TradingView `ta.ema` 一致。warmup 不足 5×span 时
  仍输出数值但标记 `reliable: false`。

## 已知未实现

- TD Countdown 13（规则分支复杂，实现不当会制造伪信号；只有 Setup 9 + Perfection）
- 基本面否决层（需人工检查盈利周期、毛利率、资本开支）
- 市值里程碑映射（按项目决定不移植：市值是股价的线性变换，不提供独立方向信息）
- A 股数据源（Provider 抽象已就位，接 Tushare 不需要改动上层）

## 前向验证结果

```bash
jta forward MU SNDK NVDA AMD AVGO META SOXX -b SOXX \
    --start 2025-08-01 --end 2026-07-25 --horizon 20 --out fwd.parquet
jta forward-report fwd.parquet
```

逐日用 `--as-of` 回放（输出只能看到当天为止的数据），记录当时给出的关键位，
再用之后 20 根 bar 的行情评估。**对照组是同侧、同样远近、但没有任何结构依据的随机价位**——
不做这个对照，任何命中率都说明不了问题。

判定口径：触及 = 之后 20 根内 low/high 进入 0.1 ATR 容差；
守住 = 触及后反向离开 >= 1 ATR 且期间未收盘穿越 0.5 ATR；失守 = 先出现收盘穿越。
去重：同一价位在 0.25 ATR 内反复出现只算一次观察。

样本：7 个标的 × 2025-08-01 至 2026-07-25，1440 条真实记录 / 1439 条对照，
其中 1022 / 868 条被触及并判定。

### 控制距离后，关键位与随机价位没有可检测的差异

| 距现价 | 真实 n | 守住率 | 对照 n | 守住率 | 差值 | z |
|---|---:|---:|---:|---:|---:|---:|
| 0–0.5 ATR | 481 | 42.4% | 53 | 60.4% | −18.0% | −2.54 |
| 0.5–1 ATR | 235 | 57.4% | 168 | 57.1% | +0.3% | 0.06 |
| 1–2 ATR | 224 | 59.8% | 325 | 58.2% | +1.6% | 0.37 |
| 2+ ATR | 82 | 64.6% | 322 | 60.2% | +4.4% | 0.74 |

必须分桶：真实关键位大量聚集在现价附近，而随机对照散布到 3 ATR，
距离本身就强烈影响触及率与穿越概率。不控制这一点，比较的是距离而不是结构。

证据命中数也没有单调关系（3/8 → 51.7%、4/8 → 48.5%、5/8 → 53.1%），全在硬币水平。

### 八项证据里只有一项在校正后显著

| 证据 | 命中守住率 | 未命中守住率 | 差值 | z |
|---|---:|---:|---:|---:|
| index（基准指数同向） | 57.9% | 46.6% | **+11.3%** | **3.61** |
| ema_cluster | 53.1% | 48.8% | +4.3% | 1.34 |
| td9 | 52.9% | 51.4% | +1.5% | 0.24 |
| trendline | 50.6% | 52.7% | −2.1% | −0.66 |
| price_action | 50.4% | 53.6% | −3.2% | −0.97 |
| extension_fib | 48.6% | 51.7% | −3.1% | −0.51 |
| primary_fib | 51.0% | 54.6% | −3.6% | −0.80 |
| horizontal | 51.0% | 65.7% | −14.7% | −1.80 |

做了 8 次比较，Bonferroni 校正后需要 |z| > 2.69。只有 `index` 越过。

**但 `index` 测的很可能不是关键位质量。** 它的判定是"支撑侧 + 指数 EMA 多头"或
"压力侧 + 指数 EMA 空头"，本质是顺势方向过滤，任何顺势策略都会得到类似结果，
与 Fib 或共振无关。

`ema_cluster` 在另一组样本（8 个标的、不带基准）上曾达 z=2.42，换一组标的就掉到 1.34——
这种在样本间的漂移本身就说明它是噪声。

### 局限

- 单一时期，且是科技股强牛市；样本标的高度相关，有效样本量远小于记录条数
- 守住/失守的阈值（1 ATR / 0.5 ATR）与 horizon=20 都是选定参数
- 这是**缺乏证据**，不是"证明无效"

### 计划级回测推翻了上面两条改动

关键位守不守得住，和照计划交易能不能赚钱，不是同一件事。
`jta backtest` 在 4H 粒度上模拟完整流程：限价成交、止跌确认、分批止盈、
跟踪止损、跳空按开盘价结算。

样本：25 个标的（15 只半导体 + 5 只大盘/行业 ETF + 5 只非科技对照）
× 2025-09-01 至 2026-06-25，4007 条计划、407 笔成交。

**选点确实有价值——这是 P5 没能给出的答案：**

| | 触发 | 胜率 | 期望 | 平均盈 / 亏 |
|---|---:|---:|---:|---|
| 真实计划 | 407 (10%) | 46.9% | **+0.498R** ±0.135 | +2.21 / −1.02 |
| 随机入场（同样的触发与风控规则） | 360 (9%) | 39.4% | **+0.019R** ±0.072 | +1.52 / −0.96 |

差 +0.479R，z = 3.12。随机组期望几乎正好是 0，这本身是健全性检查：
若模拟里有让所有交易都赚钱的 bug，随机组也会是正的。

价值不在"关键位本身更容易守住"，而在**关键位 + 确认信号 + 结构化风控**这一整套组合。

**但按 P5 结论做的两条改动都没有站住：**

| | 触发 | 期望 | 总 R |
|---|---:|---:|---:|
| 关闭距离过滤 | 625 | +0.505R | 315.6R |
| 开启距离过滤（0.5 ATR） | 407 | +0.498R | 202.7R |

差 −0.007R、z = −0.04：砍掉 35% 的机会，单笔质量毫无提升，总收益少三分之一。
原因是计划本来就要求出现止跌确认才入场，这一步已经过滤掉了会跌穿的情形，
再叠一层距离过滤属于重复劳动。

指数方向同样反了：非多头时期望 +0.871R（n=93），多头时 +0.388R（n=314），
z = 1.48。不显著，但没有任何证据支持"非多头就减半"。

**因此两条默认都已关闭**（`MIN_ENTRY_DISTANCE_ATR = 0.0`、
`ADVERSE_INDEX_SCALE = 1.0`），机制保留为 `build_plans` 的参数，
有了新数据可以重新评估，不必改回代码。

### 回测的稳健性与局限

25 个标的中 18 个期望为正，按标的分组的期望中位数 +0.517R；
前半段 +0.260R、后半段 +0.735R，两段都正——不是靠一两只票撑起来的。

局限必须一起读：只有 10 个月且是牛市，三套计划都做多，有系统性顺风；
未计滑点与佣金，而 21.6% 的止损是跳空触发的，真实成交更差；
最差单笔 −9.76R，一次跳空能吃掉十笔正常盈利；
15 只半导体高度相关，有效样本量远小于 407。

### 仍然不做的

`hits` 是证据类型的计数，不是强度评分，更不是胜率。代码里没有做加权求和，
也不打算根据这次结果去拟合权重——1000 条相关样本不足以支撑那种拟合。

这套工具真正站得住的部分是纪律侧：确定性可复现的位置、口径一致的数据、
入场前定死的失效位、按结构位反推的仓位。选点本身没有被证明有超额价值。
